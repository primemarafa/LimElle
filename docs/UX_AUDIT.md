# Lim'Elle UX audit

## Findings

- Boutique and Catégories target the same catalogue anchor. They need distinct roles.
- Journal currently targets the services block. Its label should match its destination.
- Header search currently jumps to the catalogue without a search action.
- Header account currently jumps to the help area without a customer account flow.
- The lower CTA and footer CTA duplicate the same action.
- Some sections need stronger vertical rhythm between headings, cards and blocks.

## Navigation model

Accueil -> hero
Boutique -> products
Catégories -> category cards
À propos -> brand story
Journal -> services / sur-mesure
Contact -> FAQ and help

## Visual rhythm

Use consistent vertical section padding.
Keep visible separation between headings, body copy and actions.
Use consistent gaps and internal card padding.
