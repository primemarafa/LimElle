# Lim'Elle, layout reference

The approved homepage mockup is the layout reference for the production frontend.

## Desktop order

1. Cream header with logo, signature, navigation and action icons.
2. Split hero with editorial copy on the left and a dominant African portrait on the right.
3. Dark green reassurance band with four benefits.
4. Categories section with four large image cards.
5. Featured products section with five product cards and a "Voir tout" action.
6. Trust strip with secure payment, customer proof and WhatsApp support.
7. Dark green footer with slogan and shop CTA.

## Interaction placement

Hero actions: "Découvrir la boutique" then "Commander sur WhatsApp".
Category cards: "Découvrir" button inside each card.
Featured products: product image, name, descriptor, price and cart action.
Header: search, account and cart actions.

## Responsive behavior

Desktop uses the approved wide composition.
Mobile stacks the same sections while preserving the action hierarchy and visual rhythm.

## Constraint

Business flows already implemented must stay functional: catalogue loading, filters, product details, cart, checkout, transport estimate, WhatsApp, invoices and order confirmation.
