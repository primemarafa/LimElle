# Lim'Elle, direction artistique de référence

Cette version reprend la maquette approuvée comme référence visuelle principale.

## Structure de la page d'accueil

1. Header crème avec logo Lim'Elle, navigation et icônes.
2. Hero pleine largeur avec texte à gauche et portrait africain premium à droite.
3. Bandeau de confiance vert profond avec quatre bénéfices.
4. Section « Nos catégories » avec quatre cartes visuelles.
5. Section « Produits phares » avec cinq cartes produit.
6. Bandeau confiance avec paiement, clientes satisfaites et WhatsApp.
7. Footer vert profond avec slogan et CTA.

## Palette

- Ivoire : #F8F3EA

- Cuivre : #B8753C
- Brun texte : #2D2924

## Image direction

Les images doivent rester élégantes, contemporaines et africaines.
Éviter les images de village, folkloriques ou trop artisanales.
Privilégier les portraits éditoriaux, les matières premium, les compositions produit studio et les accessoires modernes.

## Règle catalogue

Les URLs d'images venant de la base PostgreSQL sont la source d'affichage du catalogue. Le fichier assets/visuals.js ne remplace pas ces URLs automatiquement.
Toute nouvelle série d'images catalogue doit donc passer par une migration SQL ou une synchronisation explicite avec la base.
